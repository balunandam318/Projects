Search Github Profile

This project is a simple JavaScript-based web application that fetches and displays GitHub user profile information using the GitHub API. Users can enter any valid GitHub username, and the app dynamically retrieves and presents the profile data within a clean and responsive template.

✨ Features:

  • Fetches real-time data from GitHub using fetch() API
  • Displays user profile picture, name, bio, location, number of repositories, followers, and following count
  • Clean, user-friendly UI with responsive design
  • Error handling for invalid usernames or failed API requests
  • Modular and easy-to-understand JavaScript code structure

🌐 Technologies Used:

  • HTML, CSS, JavaScript (Vanilla JS)
  • GitHub REST API
  • Responsive Web Design
